# LLM 기반 AFS 탐색 방법 문서화

날짜: 2026-09-15 UTC.
요청: 실험 전에 현재 LLM 기반 AFS 탐색 방법을 설명하고 문서로 보존.

## 확인 및 변경

- 시작 시 `git status --short` 출력이 비어 있어 작업 트리가 깨끗함을 확인.
- v2 expanded.py, CLI, YAML, 기존 확장 문서, feedback 판정 코드와 프로젝트 감사/
  로드맵을 읽고 실제 구현을 기준으로 설명을 작성.
- `scene2test/docs/LLM_AFS_METHOD_KO.md` 추가: 목적, 입력, 부분 공간 출력,
  혼합 샘플링, 장면 컴파일, 결과 검증, ExtraTrees와의 차이, 평가 한계와 코드 연결.
- 핵심 명확화: LLM은 실패 판정기/로봇 제어기/학습된 수치 surrogate가 아닌
  환경 부분 공간 제안자. 현재 mixed 값 추출은 random이며 Sobol은 별도 대조군.
- 네 슬롯 50/25/25 배분과 실패 이력이 없을 때 75/25, 15% 국소 반경,
  미지정 축의 원래 범위 추출, 직육면체 범위 표현의 한계, 고정/가변 도착점 명시.
- 실제 실패 인정은 유효 execution의 navigation_success를 사용하며 생성 무효나
  인프라 오류와 분리함을 설명. 코드/자원/산출물 확인을 거친 이력만 재사용.
- attempt budget과 valid rollout budget 구분, 아직 없는 자동 반복/공정 비교/
  의미적 중복 제거를 명시. LLM 슬롯 ablation은 향후 제안이며 구현 완료가 아님.

## 검증과 범위

문서와 상대 링크 대상 존재 여부를 정적으로 확인한다. 코드·설정 변경, API 호출,
GPU rollout, 새 성능 실험은 없음. 116개 테스트/10개 유효 번들은 9월 13일의
기존 기록으로 인용했으며 이번 실행 결과로 기술하지 않음.
