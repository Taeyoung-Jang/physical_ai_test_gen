신규 문서: `scene2test/docs/GPT6_ROBOT_CLEAR_PATH_PLAN.md`.
작은 시뮬레이션 시나리오(상자 1개 밀기→경로 개방→목표 이동)를 첫 목표로 제안.

0 자세 PD 유지, terrain_worker의 충돌 판정, 로컬 GR00T decoupled WBC 문서/폴더.

동적 물체 추가 시 qpos 매핑을 검증하는 기술 관문을 두었음.

OpenAI Docs 스킬로 공식 GPT-6 모델 문서의 이미지/구조화 출력 지원 확인.
이를 상위 판단 인터페이스 근거로만 사용하며 물리 조작 성공과 구분.
