# 평가 지표의 정의와 집계 기준 재확인

2026-10-17 UTC. 평가 목표 달성 계획을 세우기에 앞서 기존 정의를 확인했다.
목표는 FDR 30% 이상, Random 대비 상대 Gain 20% 이상, 고정 6종 중 4종 이상 발견이다.
아래는 기존 목표 중심 평가와 현재 측정 코드의 계약이며 새로운 평가 기준으로 변경한 것이 아니다.

## 실패와 실험 단위

한 번의 시험은 한 환경에서 고정된 로봇 시스템이 최초 goal을 수행하는 하나의 rollout이다.
환경 JSON 수, GPT 호출 수, 접촉 수가 시험 수는 아니다. 예를 들어 로봇 정책을 10회 호출해
끝낸 하나의 episode는 시험 1회다.

유효한 실행에서 사전에 정한 목표를 달성하면 PASS, 고정 예산 종료 또는 로봇의 종료
선언까지 달성하지 못하면 FAIL이다. API 장애·수치 파손·필수 기록 누락 등은 유효 FAIL이
아니며 제외 사유와 비용을 따로 남긴다. 예산 종료 FAIL은 무제한 시간에서도 불가능함을
뜻하지 않는다. 현재 이동 목표는 목표 반경과 체류 조건을 함께 포함한다.

접촉·넘어짐·계획기의 no_path만으로 FAIL을 만들지 않는다. 복구 후 goal을 이루면 PASS다.
평가기나 AFS가 특정 경유점·밀기 동작·정답 경로를 강제하지 않는다.

## 실패 발견율

`FDR = 유효 FAIL 수 / (유효 PASS 수 + 유효 FAIL 수)`

목표는 AFS의 FDR 30% 이상이다. 유효 실행 100회에서 FAIL 30회를 관측하면 30%다.
유효 실행 0회이면 0%가 아니라 계산 불가다.

독립적으로 다시 실행한 반복도 시험 예산과 분모에 포함되며, 같은 기록의 복사본은 중복
집계하지 않는다. 초기 탐색·완화·경계 확인·재현 반복도 모두 실제 실행이면 예산을 소비한다.
따라서 FDR은 고유 실패 장면의 비율이 아니다. 같은 실패를 반복해 수치를 높이는 현상을
숨기지 않도록 고유 실패 장면 수와 반복 실패 수, 탐색 단계별 결과를 함께 보고한다.

## 실패 탐색 성능 향상

`Gain = (FDR_AFS - FDR_Random) / FDR_Random`

목표는 상대 Gain 20% 이상이다. 양쪽 각각 유효 100회에서 Random FAIL 25회, AFS FAIL
30회라면 `(0.30 - 0.25) / 0.25 = 0.20`으로 목표에 해당한다. 절대 차이는 5%p이며
20%p 증가가 아니다. Random FAIL이 0이면 상대 Gain은 정의되지 않으므로 null로 두고
절대 차이를 보고한다. 작은 상수를 넣거나 무한대로 처리해 달성이라고 하지 않는다.

두 방법의 환경 허용 범위, 로봇·관측·정책·목표·회당 예산·평가기와 seed별 유효 시험
예산을 맞춘다. Random은 사전에 선언한 공통 전체 domain 분포에서 뽑는다. 같은 환경
목록을 그대로 실행해야 한다는 뜻은 아니다. 후보 선택 전략이 비교 대상이다.
제외 실행은 FDR 분모 밖이지만 총 시도 예산과 비용에서 사라지지 않는다. 최대 시도
한도 내 유효 예산을 못 채우면 비교 미완료로 남기며 무한 대체 실행하지 않는다.
외부 과거 이력을 사용한 개발 세션과 독립 AFS/Random 비교는 구분한다.

## 실패 유형 다양성

`Coverage = 근거를 갖춰 발견한 서로 다른 실패 유형 수 / 6`

목표는 동일한 시험 예산에서 적어도 4종, 비율로는 약 66.7%다. 여러 seed를 합친 유형
합집합은 그 전체 시험 수의 결과이며 한 seed의 예산으로 발견한 것처럼 보고하지 않는다.

다음 여섯 항목이 사전 정의한 유형이며, 설명은 측정 대상의 개념이지 모두 구현된 규칙이 아니다.

| 유형 | 필요한 근거의 개념 |
|---|---|
| 충돌 | 실제 접촉과 당시 행동·진척의 연관. 발의 바닥 지지나 의도한 접촉만으로 실패 분류하지 않음 |
| 도달 불가 | 로봇·task 제약과 목표 접근 불가에 대한 독립 근거. no_path 한 번은 충분하지 않음 |
| 장애물 간섭 | 장애물 배치, 정체, 재계획·조작 시도, 진척과 최종 결과 |
| 목표 위치 점유 | 물체의 목표 영역 점유와 지속 시간, 제거 여부, 최종 결과 |
| 작업자 안전 위험 | 선언된 사람 영역, 로봇과의 거리·위험 노출 시간 |
| 인식 오류 | 로봇에게 제공한 관측과 구조화된 인식 판단, 평가용 정답의 불일치 |

현재 공식 집계는 유효 goal FAIL에 검증된 규칙과 증거가 연결된 경우에 한한다. LLM의
예상 유형은 정답 라벨이 아니다. 현재 primary_family는 장면별 보수적으로 하나 또는
UNKNOWN으로 관리하며 모호한 여러 라벨로 발견 수를 늘리지 않는다. 유형 연관 근거와
물리적 원인 확정도 구분한다. 같은 유형의 실패를 20회 얻어도 유형 수는 1종이다.

현재 구현은 충돌·장애물 간섭·목표 점유 세 규칙을 지원한다. 미지원 유형을 분모에서
빼지 않고 분모 6을 유지한다. 부분 측정은 coverage null과 관측 하한으로 보고한다.
코드에 규칙을 추가하거나 환경 변수를 여러 개 바꾼 것만으로 유형을 발견한 것은 아니다.

## 계획 수립 전에 유지할 구분

세 지표는 각각 실패를 얼마나 많이, Random보다 얼마나 더, 얼마나 다양한 종류로
찾는지를 측정한다. 같은 실패의 반복은 FDR에 들어가지만 고유성이나 다양성을 대신하지
못하므로 회귀 재현성·고유 실패 수·총비용을 보조 지표로 함께 본다.

안전 사건과 goal 실패는 현재 분리한다. 위험 행동이 있었어도 goal을 달성한 기록은
goal-only FDR/실패 Coverage에 넣지 않는다. 안전 위반 자체를 실패로 삼는 평가가
필요하면 사전에 별도 task/profile을 정해야 하며 기존 결과를 소급 변경하지 않는다.

후속 계획에서는 위 정의를 유지한 상태에서 평가 domain과 예산·seed, 유형별 증거 규칙,
달성 주장의 반복·불확실성 기준을 구체화해야 한다. 현재 표본의 점추정이 목표를 넘는 것과
통계적으로 일반화된 성능을 입증하는 것은 같지 않다.
