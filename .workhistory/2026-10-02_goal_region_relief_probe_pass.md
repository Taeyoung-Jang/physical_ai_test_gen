## 행동과 성공 조건

GPT는 먼저 최종 목표 (7,0)에 `plan_path`를 요청했고 경로를 얻었다. 이후 같은 최종 목표로
`navigate_to`를 네 번 요청했다. 모든 계획 결과가 path_found였고, 직접 move나 push는 없었다.
계획 조회는 이동 경로 실행이 아니며 그 처리 중 기존 자세 유지와 미세한 물리 움직임은 있을 수 있다.

약 6.630s 실행됐고, 종료 phase는 navigate_goal_hold다. 0.12m 도착 허용 반경 진입 후
hold 자체는 0.065s였다. 나머지 체류는 목표 영역 안으로 접근하면서 쌓였으므로 정지한 채
1초를 기다린 것으로 설명하면 안 된다. 10회 호출 중 5회가 남았고 사후 유예나 예산 연장은 없다.
마지막 저장 상태는 60.950s/체류 0.995s이며 full-rate 최종 판정과 표본 간격 차이가 있다.

상태 1,220개, 접촉 표본 54,179개에서 접촉 대상은 모두 clear_floor다. 이벤트는 접촉
시작/종료 각 850개이며 넘어짐과 바닥 외 로봇 접촉은 기록되지 않았다. 경로 연결 차단,
clearance recovery, within-action replan은 0이다. 표본의 최소 base 높이는 0.740678m,
최대 기울기는 8.999도다. P1 상태·이벤트·행동·물체 이동은 AVAILABLE이며 warnings는 없다.
상자 XY 순변위 약 4.40e-9m는 수치 잡음 수준이다. 이를 물체 조작 성공이나 실패로 보지 않는다.

## 이전 기준과 다른 점

| 항목 | 기준 0.5 반복 | 이번 완화 0.75 |
|---|---:|---:|
| 목표 결과 | PASS | PASS |
| 로봇 API 호출 | 9 | 5 |
| 실행된 행동 | 이동 5회 + 직접 move 3회 | 경로 조회 1회 + 이동 4회 |
| 시뮬레이션 시간 | 201.110s | 60.955s |
| 행동 실행 시간 합 | 40.975s | 36.840s |
| 최종 목표 거리 | 0.167210m | 0.112632m |

이번 관측은 완화 후보에서 직접 목표 경로를 이용해 더 적은 호출로 성공했다는 근거다.
시뮬레이션 시간에는 추론 대기가 포함되므로 시간 차이 전체를 보행 속도 또는 물리 난이도 차이로
해석하지 않는다. 장면은 하나의 설정 축만 바뀌었지만 원격 모델 응답은 비결정적이다. 각 장면
한 번의 대조로 인과나 단조 난이도를 확정하지 않으며, 두 결과가 모두 PASS라 실패 경계도 아니다.

저장된 memory에는 fraction 1.0 PASS 1회, 0.5 PASS 2회, 0.75 PASS 1회가 있다.
중복과 PASS/FAIL bracket은 0이다. 후보 행의 baseline_pass=1은 상속된 기준 장면 성공이며
이번 후보의 새 성공은 pass=1에 기록됐다. 아직 실행 전인 0.25에도 baseline_pass=1이 있어
이 둘을 혼동하면 안 된다. 가설의 정식 인과 판정이나 새 실패 유형·Gain은 부여하지 않는다.

파일 전체 디코딩을 검증했다. 이번 검토에서 전체 영상을 육안 재생한 것은 아니며 GIF도 만들지 않았다.
