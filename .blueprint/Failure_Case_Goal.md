## 평가 지표
- 실패 발견율 (Failure Discovery Rate)
    - 동일한 테스트 횟수에서 얼마나 많은 실패 사례를 발견했는지 평가
    - 테스트 자동 생성 기법의 효과를 측정하는 핵심 지표
- 실패 탐색 성능 향상 (Failure Discovery Gain)
    - 무작위(Random) 테스트 대비 얼마나 더 많은 실패 사례를 발견했는지 평가
    - 제안 기법의 탐색 효율 향상 정도를 측정
- 실패 유형 다양성 (Failure Diversity Coverage)
    - 충돌, 도달 불가, 장애물 간섭, 목표 위치 점유, 작업자 안전 위험, 인식 오류 등 사전에 정의한 주요 실패 유형 6종 중 4종 이상을 자동 발견
    - 특정 실패 유형에 치우치지 않고, 다양한 환경 변화 조건에서 실패를 탐색할 수 있는지 평가

## 개선 방법
- 3D Scene Graph 기반 테스트 공간 자동 구조화
    - 3D Object 위치, 크기, 역할, 객체 간 거리, 로봇 작업 반경, 목적지 점유 여부, 경로 차단 가능성 등을 3D Scene Graph 형태로 구조화
    - 기존처럼 사람이 테스트 조건을 일일이 정의하는 방식이 아니라, 실제 작업공간 구조를 기준으로 테스트 후보를 자동 생성할 수 있는 기반을 마련
- 물리 제약 기반 Failure Candidate 자동 생성
    - 목표물 위치 이동, 장애물 접근, 경로 차단, 목적지 점유, 작업자 접근, 카메라 가름 등 주요 실패 유발 조건을 장면 변형 마라미터로 정의
    - 생성된 후보가 객체 충돌, 테이블 범위, 로봇 베이스 간섭, 그리퍼 접근 가능성, 시뮬레이터 실행 가능 조건을 만족하는지 사전 검증
- Active Failure Search 기반 실패 가능 장면 우선 탐색
    - 초기 테스트 실행 결과를 기반으로 모델을 학습하고, 실패 가능성, 예측 불확실성, 안전 둥요도, 테스트 다양성을 함께 고려해 다음 테스트 장면을 선택
    - 전체 후보를 모두 실행하지 않고, 실패 가능성이 높은 장면을 우선 검증함으로써, 제한된 테스트 예산 안에서 더 많은 Fail/Blocked 조건을 발견
    - Random Search 또는 수동 테스트 대비 실패 발견 효율, 경계 조건 탐색, 실패 유형 커버리지를 개선
- LAM/VLA 행동 검증 및 회귀 테스트 자산화
    - LAM/VLA 정책의 실행 결과를 RolloutTrace로 저장하고, 잘못된 객체 선택, 잘못된 subgoal 순서, 경로 이탈, 안전 규칙 위반, 회복 실패 여부를 자동 판정
    - 단일 시점의 충돌뿐 아니라 행동 sequence 전체에서 reachability, collision, clearance, goal satisfaction, human safety distance, temporal safety 조건을 종합 검증
    - 발견된 실패 조건, 최소 perturbation boundary, 재현 조건, 실패 원인, 개선 권고를 failure memory에 저장하여, 정책 또는 현장 조건 변경 시 회구 테스트셋으로 재사용

## 개선 목표
- 실패 발견율: 30% 이상 달성
- 실패 탐색 성능 향상: Random Search 대비 20% 이상 향상
- 실패 유형 다양성: 동일 테스트 샘플 수 기준 6종 중 4종 이상 발견
